# Участие в разработке

Требования: macOS 14+, полный Xcode со Swift 6, Python 3 для проверок упаковки. Нет сторонних Swift-пакетов и серверной части.

```sh
bash scripts/swift.sh test
bash scripts/swift.sh test -c release
bash scripts/build-app.sh
```

`scripts/swift.sh` направляет временные файлы SwiftPM в игнорируемую папку `temp/`. Основная программа и `TashAirCore` собираются SwiftPM, расширение WidgetKit — проектом `packaging/TashAirWidgets.xcodeproj`, который подключает локальный продукт `TashAirCore`.

## Устройство

- `Sources/TashAirCore`: поставщики и разбор ответов, HTTP-клиент, кэш, модели, локализация, чистая логика уведомлений.
- `Sources/TashAir`: строка меню и панель SwiftUI, настройки, разрешения и доставка уведомлений.
- `Sources/TashAirWidgets`: независимое расширение WidgetKit с собственными запросами и кэшем.
- `Tests/TashAirCoreTests`: синтетические ответы, актуальность, восстановление, конкурирующие запросы, состояния порогов и календарь сводки.

## Проверка реальных данных и внешнего вида

```sh
bash scripts/verify-app.sh
bash scripts/render-widgets.sh
python3 scripts/check-launch.py --seconds 30
```

Первая команда собирает приложение, проверяет все пять реальных API и сохраняет отчёт и PNG экранов для обоих языков и тем в `temp/verification`. Вторая рендерит реальные SwiftUI-представления виджетов со свежими, сохранёнными и отсутствующими данными. Отрисовка требует рабочего стола macOS; запросы настоящие, уведомления не отправляются, пользовательские настройки не меняются. Проверка запуска удерживает отдельный процесс 30 секунд, затем завершает только его.

Дополнительно вручную проверьте установленную копию: строку меню, навигацию, прокрутку, разрешение уведомлений, включение/выключение автозапуска, добавление виджетов через галерею macOS и переходы из них. Время обновления WidgetKit зависит от системы.

## Упаковка

```sh
TASHAIR_UNIVERSAL=1 bash scripts/build-dmg.sh
python3 scripts/check-distribution.py --universal
```

При наличии собственной Developer ID Application можно задать `TASHAIR_SIGN_IDENTITY`. Это включает подпись, но не нотариализацию. Сертификаты и пароли не входят в репозиторий. CI собирает и проверяет архивы, без публикации релизов и сайта.

## Сайт документации

Документация собирается в статическую книгу с оглавлением, поиском и переходами между страницами. Исходники берутся из существующих Markdown-файлов; отдельная главная страница находится в `web/index.md`. Сайт не использует сторонние шрифты, аналитику и серверный поиск.

```sh
python3 -m venv temp/docs-venv
temp/docs-venv/bin/python -m pip install -r web/requirements.txt
temp/docs-venv/bin/python scripts/build-docs.py
temp/docs-venv/bin/python scripts/check-docs.py
python3 -m http.server 8768 --bind 127.0.0.1 --directory temp/site
```

При локальном просмотре откройте `http://127.0.0.1:8768/`. GitHub Actions собирает и проверяет книгу на каждой ветке и в PR, а публикует только из `main`. В Settings → Pages выбирается GitHub Actions. Инструкция — в [публикации](docs/PUBLISHING.md). Ссылки на исходники привязаны к SHA сборки через `TASHAIR_SOURCE_REF`; локально используется текущий HEAD, в архиве без Git — `main`.

## Правила

- Не заменяйте пропуски нулями, прогноз наблюдением или время загрузки временем измерения.
- Сохраняйте разделение глобальных и местных, модельных и наблюдаемых показателей.
- При изменении источника добавляйте содержательный синтетический пример в тесты; реальные базы в Git не сохраняйте.
- Обновляйте оба языка. Статические подписи App Intents дополнительно находятся в `packaging/ru.lproj` и `packaging/uz.lproj`.
- Новая ветка до первой правки. Не работайте в `main`/`develop`, не выполняйте push и merge без инструкций владельца. В сообщениях коммитов и PR нет подписей ИИ.
- Состояние порогов сохраняется перед доставкой: при сбое доставки приоритет — отсутствие повторов. Повреждённый журнал уведомлений блокирует доставку, чтобы перезапуск не дублировал события.

Баг-репорт: версия, macOS и архитектура, шаги воспроизведения, источник, дата данных и обезличенный снимок экрана. Не прикладывайте личные настройки целиком.
