# История изменений

## Не выпущено

- Советы по текущему воздуху, выбору респиратора, жаре, холоду, ветру, осадкам и УФ на двух языках; ссылки на источники и защита от устаревших данных.

- Цветной индикатор строки меню по шести категориям US AQI, с нейтральным состоянием для сохранённых и отсутствующих данных.
- Автоматическое обновление цвета при изменении показателя, общая палитра и шкала с текущим диапазоном в панели.

## 0.1.0 — 2026-11-07

- Первое приложение TashAir для macOS 14+ на русском и узбекском.
- Модельный воздух CAMS Global, погода и 30-дневная история Open-Meteo.
- Местные солнечные показатели, глобальный Kp и солнечные вспышки NOAA.
- Пороговые уведомления, ежедневная сводка, три размера виджетов.
- Независимые источники и кэш, сохранение данных при сетевых сбоях.
- Сборка приложения, универсальный DMG/ZIP, тесты и CI.
- Публичный репозиторий и книга документации с поиском для GitHub Pages.
- Совместимое получение настроек уведомлений в Swift 6 со старыми macOS SDK.

Developer ID и нотариализация не выполнены.
